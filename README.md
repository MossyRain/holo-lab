# HOLO LAB v1.3

変更点
- 輪郭領域を「輪郭線」として扱うのをやめ、他の塗り面と同程度の明るさで発色
- 輪郭領域の彩度・色相変化量を大幅に増加
- 背景ホロを強化
  - 色変化量・彩度・不透明度を増加
  - 3色の広い色場が傾きで大きく移動
- 傾き感度を大幅にアップ
  - 少ない手首の傾きで大きな色相変化
  - 寄り目で中央像を見ながら操作しやすい設定
- タッチ操作も中央付近の感度をアップ
- iPhoneステータスバー白帯対策を強化
  - apple-mobile-web-app-status-bar-style を black に変更
  - theme-colorを常時黒
  - html/body/shellの物理背景を常時黒
  - メニュー本体の薄いグレー背景は維持
- Service Workerキャッシュ停止方針は継続
