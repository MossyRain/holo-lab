# HOLO LAB v1.2

変更点
- 輪郭線を「暗い線」ではなくホログラム素材として強く発色
  - 彩度を上げ、角度によって明るいシアン・紫・緑などまで変化
  - 明度も角度に応じて連続変化
- キャラクター外側の銀背景にもホロ色変化を追加
  - 暗い銀灰色を残しながら低彩度の色場が傾きで滑らかに移動
  - 左右画像にはこれまで同様の位相差を付与
- 2枚表示中のiPhoneステータスバー周辺を黒背景へ統一
  - html/body/shellの物理背景を黒化
  - ビューア表示時theme-colorを黒へ切替
  - apple-mobile-web-app-status-bar-styleをblack-translucentへ変更
- メニュー画面自体は従来の薄いグレーを維持
- 直角シールエッジ、暗め銀灰色、左右色位相差、Safe Area対応を維持
- 開発中のService Workerキャッシュ停止方針を維持
