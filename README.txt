聖虚MIRA爺 ホロ用領域マスク v0.1

元のMIRA爺画像を描き直さず、実画像の色領域から粗いマスクを抽出しました。
目的は「画面全体に虹グラデーションを重ねる」のではなく、各色面を独立したホロ位相として動かすことです。

01_dark_lines    現在の黒輪郭。次版では黒固定にせず独立したカラー位相へ。
02_purple        紫系の面
03_teal          緑〜青緑系の面
04_gold_yellow   金〜黄色系の面
05_orange_red    炎など橙〜赤系の面
06_skin_tan      肌・茶系
07_silver_white  白髪・白〜銀系

これは自動抽出の第一段階なので、同じ元色でも意味の異なる部位が一部同じマスクに入っています。
次はこのマスクを使って各領域ごとに異なる色相周期・位相を与えるアプリ実験ができます。
